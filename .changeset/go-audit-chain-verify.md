Add `verifyGoAuditChain` to verify an audit chain exported by theauth-go from TypeScript. It rebuilds Go's hash input byte for byte (struct key order, HTML-escaped strings, microsecond timestamps, pseudonyms) and reports the first failure as `hash_mismatch`, `prev_hash_mismatch`, `seq_gap`, `seq_duplicate`, `unsupported_hash_version`, `pseudonym_mismatch` or `malformed_row`. It runs on Web Crypto only. The Go chain has no HMAC mode, so the verifier cannot detect a suffix rewritten by someone who can write the table, and it cannot detect truncation.

The CLI gains `theauth audit verify-go <file.json|ndjson>`. Conformance vectors generated by the real Go code ship in the test fixtures.
