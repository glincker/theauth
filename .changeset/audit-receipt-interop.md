Audit receipts now have conformance coverage against the Go library, and the audit chain has published test vectors. The Go receipt fixture is vendored and verified in the normal test run, `packages/core/tests/fixtures/audit-chain-vectors.json` holds row hash vectors for hash versions 1 and 2 (generated by `scripts/gen-audit-chain-vectors.mjs`), and `docs/audit-receipts.mdx` specifies the leaf encoding and what does and does not interoperate with `theauth-go` (receipts do, the chains do not).

Migrations and `skipMigrations` startup now throw `AUDIT_SECRETS_LAYOUT_MISMATCH` when `theauth_audit_secrets` already exists with a layout this library did not create, for example because `theauth-go` created it in the same database. The table is not touched. Databases that use only TheAuth are unaffected; if you hit the error, give each library its own database or schema.

`chainPayload` is exported from the audit chain module so offline verifiers can build the exact hashed string.
