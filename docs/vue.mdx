`@glinr/theauth-vue` provides Vue 3 composables and an app plugin for building auth UIs. It works with Vite, Nuxt, and any Vue 3 setup.

## Installation

```bash
pnpm add @glinr/theauth-vue
```

## Setup

Register the plugin in your Vue app:

```typescript title="main.ts"
import { createApp } from 'vue';
import { createTheAuthPlugin } from '@glinr/theauth-vue'; // [!code highlight]
import App from './App.vue';

const app = createApp(App);

app.use(createTheAuthPlugin({ // [!code highlight]
  basePath: '/api/theauth', // [!code highlight]
})); // [!code highlight]

app.mount('#app');
```

### Nuxt setup

In Nuxt, create a plugin file:

```typescript title="plugins/theauth.client.ts"
import { createTheAuthPlugin } from '@glinr/theauth-vue';

export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.vueApp.use(createTheAuthPlugin({
    basePath: '/api/theauth',
  }));
});
```

## useSession

Returns the current session state. Reactive, updates when the user signs in or out.

```vue title="components/NavBar.vue"
<script setup lang="ts">
import { useSession } from '@glinr/theauth-vue';

const { session, isLoading } = useSession();
</script>

<template>
  <nav>
    <span v-if="isLoading">Loading...</span>
    <span v-else-if="session">{{ session.user.name }}</span>
    <a v-else href="/sign-in">Sign in</a>
  </nav>
</template>
```

## useUser

Returns the current user object, or `null` if signed out.

```vue
<script setup lang="ts">
import { useUser } from '@glinr/theauth-vue';

const { user } = useUser();
</script>
```

## useSignIn / useSignUp / useSignOut

```vue title="pages/sign-in.vue"
<script setup lang="ts">
import { useSignIn } from '@glinr/theauth-vue';

const { signIn, isLoading, error } = useSignIn();

async function handleSubmit(email: string, password: string) {
  await signIn({ email, password });
  // Redirect on success. The composable does not navigate automatically.
}
</script>
```

```typescript title="Sign up"
import { useSignUp } from '@glinr/theauth-vue';

const { signUp, isLoading, error } = useSignUp();
await signUp({ email, password, name });
```

```typescript title="Sign out"
import { useSignOut } from '@glinr/theauth-vue';

const { signOut } = useSignOut();
await signOut();
```

## useAgents

Lists and manages agent identities for the current user.

```typescript
import { useAgents } from '@glinr/theauth-vue';

const { agents, createAgent, revokeAgent, isLoading } = useAgents();

// Create a new agent
await createAgent({ name: 'My AI assistant', permissions: ['read:data'] });
```

## Plugin configuration reference

<ParamField path="basePath" type="string" default="'/api/theauth'">Base path where your theAuth handler is mounted.</ParamField>
<ParamField path="refetch" type="RefetchOptions">Refetch the session on window focus, reconnect or an interval. Off unless set. See [Session refetch and SSR](/client-sdk#session-refetch-and-ssr).</ParamField>
<ParamField path="initialSession" type="HydrateInput | null">Session the server already resolved. Skips the first request.</ParamField>
<ParamField path="signInPath" type="string" default="'/auth/username/sign-in'">Route for `signIn`. Core has no email and password route, so point this at your own if you need one.</ParamField>
<ParamField path="signUpPath" type="string" default="'/auth/username/sign-up'">Route for `signUp`.</ParamField>
<ParamField path="identifierField" type="string" default="'username'">Body field that carries the first argument of `signIn` and `signUp`.</ParamField>
<ParamField path="storage" type="SessionStorageLike">Defaults to `window.localStorage` when the browser allows it.</ParamField>

On install the plugin shows a stored session at once, then confirms it with `GET {basePath}/auth/session`. `signOut` clears local state first, then calls `POST {basePath}/auth/sign-out` to revoke the session on the server.

```typescript
app.use(
  createTheAuthPlugin({
    basePath: "/api/theauth",
    refetch: { intervalMs: 5 * 60_000 },
  }),
);
```
