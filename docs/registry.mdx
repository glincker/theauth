theAuth publishes its React auth components as a shadcn registry. The shadcn CLI copies the source into your project, so you own and edit it. This is the same set of items the `theauth add` command installs. See [UI components](/ui-components) for the packaged versions.

## Install an item

Run the command from your app root. Each item is a single JSON file served from the repository:

```bash
npx shadcn@latest add https://raw.githubusercontent.com/glincker/theauth/main/registry/sign-in.json
```

The CLI also pulls in the items listed in `registryDependencies` (for example `theauth-base`), so you do not install those by hand. Files land in `components/theauth/` (or `src/components/theauth/`).

| Item | URL |
| --- | --- |
| `theauth-base` | `https://raw.githubusercontent.com/glincker/theauth/main/registry/theauth-base.json` |
| `oauth-buttons` | `https://raw.githubusercontent.com/glincker/theauth/main/registry/oauth-buttons.json` |
| `sign-in` | `https://raw.githubusercontent.com/glincker/theauth/main/registry/sign-in.json` |
| `sign-up` | `https://raw.githubusercontent.com/glincker/theauth/main/registry/sign-up.json` |
| `forgot-password` | `https://raw.githubusercontent.com/glincker/theauth/main/registry/forgot-password.json` |
| `two-factor-verify` | `https://raw.githubusercontent.com/glincker/theauth/main/registry/two-factor-verify.json` |
| `user-button` | `https://raw.githubusercontent.com/glincker/theauth/main/registry/user-button.json` |

Several at once:

```bash
npx shadcn@latest add \
  https://raw.githubusercontent.com/glincker/theauth/main/registry/sign-in.json \
  https://raw.githubusercontent.com/glincker/theauth/main/registry/sign-up.json
```

Components import from `@glinr/theauth-react`, so install it and wrap your app in `TheAuthProvider`.

## How the files are laid out

Each item JSON carries the full file text in `content`, so the CLI never fetches anything else. The `path` values (such as `theauth/sign-in.tsx`) are labels inside the item, not paths in the repository. The source of truth is `packages/ui/src/components`.

`registry/registry.json` is an index of all items for tooling. It has no file content, so do not pass it to `shadcn add`.

## Regenerate

After changing a component, rebuild the committed JSON:

```bash
node scripts/build-registry.mjs
```

## Check an item

The files follow the shadcn schemas at `https://ui.shadcn.com/schema/registry.json` and `https://ui.shadcn.com/schema/registry-item.json`. A quick local check that every item still has content:

```bash
node -e "for (const f of require('fs').readdirSync('registry')) if (f !== 'registry.json') { const d = require('./registry/' + f); if (!d.files.every((x) => x.content)) throw new Error(f); }"
```
