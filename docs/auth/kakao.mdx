## Setup

<Steps>
<Step>
### Get credentials

Go to the [Kakao Developers](https://developers.kakao.com) portal and create an application. Under **Kakao Login**, enable the feature and add your redirect URI. Use the app's **REST API key** as the client ID and the Kakao Login client secret as the client secret:

```
https://your-app.com/api/theauth/auth/oauth/callback/kakao
```
</Step>

<Step>
### Configure

```ts title="lib/theauth.ts"
import { createTheAuth } from '@glinr/theauth';
import { oauth, createKakaoProvider } from '@glinr/theauth/auth';

const theauth = await createTheAuth({
  database: { provider: 'sqlite-native', url: 'theauth.db' },
  secret: process.env.THEAUTH_SECRET!,
  baseUrl: 'https://your-app.com/api/theauth',
  auth: { session: { secret: process.env.THEAUTH_SECRET! } },
  plugins: [
    oauth({
      providers: {
        kakao: createKakaoProvider({
          clientId: process.env.KAKAO_CLIENT_ID!,
          clientSecret: process.env.KAKAO_CLIENT_SECRET!,
        }),
      },
    }),
  ],
});
```

```bash
KAKAO_CLIENT_ID=...
KAKAO_CLIENT_SECRET=...
```
</Step>
</Steps>

## Scopes

Default scopes: `account_email`, `profile_nickname`, `profile_image`

| Scope | What it unlocks |
|-------|----------------|
| `profile_nickname` | Kakao nickname |
| `profile_image` | Profile image |
| `account_email` | Email address (requires business verification) |

<Warning>
  Email access requires business verification in the Kakao Developer Console. Without it, only `profile_nickname` and `profile_image` are available.
</Warning>

## How it works

- Scopes are sent comma separated, as Kakao requires.
- Kakao's REST guide does not describe PKCE, so no code challenge is sent.
- The client secret is required at the token endpoint unless you turn it off for the app in the Kakao console.
- The profile call is `https://kapi.kakao.com/v2/user/me`. The numeric `id` is stored as a string, and the email, nickname and image sit under `kakao_account`.
- The email counts as verified only when both `is_email_verified` is true and `is_email_valid` is not false.
- A refresh returns a new refresh token only when the old one expires within a month.

<Info>
  `kakaoProvider` (the older preset) reads only the OIDC `sub` claim and cannot read Kakao's profile shape. It is still exported for existing code. Use `createKakaoProvider` for new setups.
</Info>

Vendor docs: [Kakao Login REST API](https://developers.kakao.com/docs/en/kakaologin/rest-api).

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/auth/oauth/authorize/kakao` | Redirect to Kakao |
| GET | `/auth/oauth/callback/kakao` | Handle callback |
