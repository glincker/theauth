## Setup

<Steps>
<Step>
### Get credentials

Go to [kick.com](https://kick.com) and navigate to **Dashboard > Developer > Applications**. Create an app and set your redirect URI:

```
https://your-app.com/api/theauth/auth/oauth/callback/kick
```
</Step>

<Step>
### Configure

```ts title="lib/theauth.ts"
import { createTheAuth } from '@glinr/theauth';
import { oauth, createKickProvider } from '@glinr/theauth/auth';

const theauth = await createTheAuth({
  database: { provider: 'sqlite-native', url: 'theauth.db' },
  secret: process.env.THEAUTH_SECRET!,
  baseUrl: 'https://your-app.com/api/theauth',
  auth: { session: { secret: process.env.THEAUTH_SECRET! } },
  plugins: [
    oauth({
      providers: {
        kick: createKickProvider({
          clientId: process.env.KICK_CLIENT_ID!,
          clientSecret: process.env.KICK_CLIENT_SECRET!,
        }),
      },
    }),
  ],
});
```

```bash
KICK_CLIENT_ID=...
KICK_CLIENT_SECRET=...
```
</Step>
</Steps>

## Scopes

Default scopes: `user:read`

| Scope | What it unlocks |
|-------|----------------|
| `user:read` | Read user profile and email |
| `channel:read` | Read channel information |
| `chat:read` | Read chat messages |

## How it works

- PKCE with S256 is required by Kick and is always sent. Client credentials go in the form body.
- The auth server is `id.kick.com`. The profile call goes to a different host, `GET https://api.kick.com/public/v1/users`, and returns `{ "data": [{ "user_id", "name", "email", "profile_picture" }] }`. `user_id` is a number and is stored as a string.
- User tokens come with a refresh token.
- Kick does not state whether the email is verified, so the OAuth plugin will not link a Kick login to an existing account by email.

<Info>
  `kickProvider` (the older preset, which reads `id.kick.com/oauth/userinfo`) is still exported for existing code. Use `createKickProvider` for new setups.
</Info>

Vendor docs: [Kick OAuth 2.1 flow](https://docs.kick.com/getting-started/generating-tokens-oauth2-flow) and [Users API](https://docs.kick.com/apis/users).

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/auth/oauth/authorize/kick` | Redirect to Kick |
| GET | `/auth/oauth/callback/kick` | Handle callback |
