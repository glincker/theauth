## Setup

<Steps>
<Step>
### Get credentials

Go to [linear.app/settings/api](https://linear.app/settings/api) and click **Create new OAuth application**. Add your redirect URI:

```
https://your-app.com/api/theauth/auth/oauth/callback/linear
```
</Step>

<Step>
### Configure

```ts title="lib/theauth.ts"
import { createTheAuth } from '@glinr/theauth';
import { oauth, createLinearProvider } from '@glinr/theauth/auth';

const theauth = await createTheAuth({
  database: { provider: 'sqlite', url: 'theauth.db' },
  secret: process.env.THEAUTH_SECRET!,
  baseUrl: 'https://your-app.com/api/theauth',
  auth: { session: { secret: process.env.THEAUTH_SECRET! } },
  plugins: [
    oauth({
      providers: {
        linear: createLinearProvider({
          clientId: process.env.LINEAR_CLIENT_ID!,
          clientSecret: process.env.LINEAR_CLIENT_SECRET!,
        }),
      },
    }),
  ],
});
```

```bash
LINEAR_CLIENT_ID=...
LINEAR_CLIENT_SECRET=...
```
</Step>
</Steps>

## Scopes

Default scopes: `read`

| Scope | What it unlocks |
|-------|----------------|
| `read` | Read access to the user's data |
| `write` | Write access to issues, comments, etc. |
| `issues:create` | Create issues |
| `app:assignIssues` | Assign issues to the app |

Scopes are sent comma separated, as Linear requires.

## How it works

- Linear has no userinfo endpoint. The profile comes from a GraphQL `viewer { id name email }` query sent as a POST to `https://api.linear.app/graphql`.
- PKCE (S256) is sent. Client credentials go in the form body.
- The code exchange returns a refresh token, and `getAccessToken` refreshes through it. Access tokens last 24 hours.
- Linear does not state whether the email is verified, so the OAuth plugin will not link a Linear login to an existing account by email.

<Info>
  `linearProvider` (the older preset, which cannot read Linear's GraphQL profile) is still exported for existing code. Use `createLinearProvider` for new setups.
</Info>

Vendor docs: [Linear OAuth 2.0 authentication](https://linear.app/developers/oauth-2-0-authentication) and [GraphQL API](https://linear.app/developers/graphql).
