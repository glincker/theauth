## How adapters work

The `kavachos` core package has zero framework dependencies. All its functions accept standard Web API `Request` objects and return `Response` objects. Framework adapters wrap the core to provide idiomatic integration with each framework's routing, middleware, and request/response conventions.

Each adapter exports a factory function that accepts a `Kavach` instance and returns a framework-specific handler (a Hono app, Express router, Fastify plugin, or route handler exports). The adapter registers all REST routes for agents, permissions, delegation, audit, dashboard stats, and (optionally) MCP OAuth endpoints.

```typescript
// Every adapter follows this pattern
const handler = kavachFramework(kavach, {
  mcp?: McpAuthModule,  // pass to enable MCP OAuth 2.1 endpoints
});
```

## Usage

<Tabs items={['Hono', 'Express', 'Next.js', 'Fastify', 'Nuxt', 'SvelteKit', 'Astro']}>
  <Tab value="Hono">
    `kavachHono` returns a `Hono` app instance. Mount it with `app.route()`.

    ```typescript
    import { Hono } from 'hono';
    import { serve } from '@hono/node-server';
    import { createKavach } from 'kavachos';
    import { kavachHono } from '@kavachos/hono';

    const kavach = createKavach({
      database: { provider: 'sqlite', url: 'kavach.db' },
    });

    const app = new Hono();
    app.route('/api/kavach', kavachHono(kavach));

    serve({ fetch: app.fetch, port: 3000 });
    ```

    With MCP OAuth:

    ```typescript
    import { createMcpModule } from 'kavachos/mcp';

    const mcp = createMcpModule({ config: { /* ... */ }, /* storage callbacks */ });
    app.route('/api/kavach', kavachHono(kavach, { mcp }));
    ```
  </Tab>

  <Tab value="Express">
    `kavachExpress` returns an Express `Router`. Mount it with `app.use()`.

    ```typescript
    import express from 'express';
    import { createKavach } from 'kavachos';
    import { kavachExpress } from '@kavachos/express';

    const kavach = createKavach({
      database: { provider: 'sqlite', url: 'kavach.db' },
    });

    const app = express();
    app.use(express.json());
    app.use(express.urlencoded({ extended: true }));
    app.use('/api/kavach', kavachExpress(kavach));

    app.listen(3000);
    ```

    With MCP OAuth:

    ```typescript
    import { createMcpModule } from 'kavachos/mcp';

    const mcp = createMcpModule({ config: { /* ... */ }, /* storage callbacks */ });
    app.use('/api/kavach', kavachExpress(kavach, { mcp }));
    ```

    <Callout type="info">
      Express requires `express.json()` and `express.urlencoded()` middleware before the KavachOS router. The adapter converts Express requests to Web API Request objects internally for MCP endpoints.
    </Callout>
  </Tab>

  <Tab value="Next.js">
    `kavachNextjs` returns route handler exports for the App Router. Mount it in a catch-all route.

    ```typescript
    // app/api/kavach/[...kavach]/route.ts
    import { createKavach } from 'kavachos';
    import { kavachNextjs } from '@kavachos/nextjs';

    const kavach = createKavach({
      database: { provider: 'sqlite', url: 'kavach.db' },
    });

    const handlers = kavachNextjs(kavach);

    export const GET = handlers.GET;
    export const POST = handlers.POST;
    export const PATCH = handlers.PATCH;
    export const DELETE = handlers.DELETE;
    export const OPTIONS = handlers.OPTIONS;
    ```

    With MCP OAuth:

    ```typescript
    import { createMcpModule } from 'kavachos/mcp';

    const mcp = createMcpModule({ config: { /* ... */ }, /* storage callbacks */ });
    const handlers = kavachNextjs(kavach, { mcp });

    export const GET = handlers.GET;
    export const POST = handlers.POST;
    export const PATCH = handlers.PATCH;
    export const DELETE = handlers.DELETE;
    export const OPTIONS = handlers.OPTIONS;
    ```

    The default `basePath` is `/api/kavach`. To change it:

    ```typescript
    const handlers = kavachNextjs(kavach, { basePath: '/api/auth/kavach' });
    ```
  </Tab>

  <Tab value="Fastify">
    `kavachFastify` returns a Fastify plugin function. Register it with `fastify.register()`.

    ```typescript
    import Fastify from 'fastify';
    import { createKavach } from 'kavachos';
    import { kavachFastify } from '@kavachos/fastify';

    const kavach = createKavach({
      database: { provider: 'sqlite', url: 'kavach.db' },
    });

    const app = Fastify();
    await app.register(kavachFastify(kavach), { prefix: '/api/kavach' });

    await app.listen({ port: 3000 });
    ```

    With MCP OAuth:

    ```typescript
    import { createMcpModule } from 'kavachos/mcp';

    const mcp = createMcpModule({ config: { /* ... */ }, /* storage callbacks */ });
    await app.register(kavachFastify(kavach, { mcp }), { prefix: '/api/kavach' });
    ```

    <Callout type="info">
      Use Fastify's built-in `prefix` option when calling `app.register()` to set the mount path. The adapter builds Web API Request objects from Fastify requests internally for MCP endpoints.
    </Callout>
  </Tab>

  <Tab value="Nuxt">
    `kavachNuxt` returns an H3 event handler. Export it as a catch-all server route.

    ```typescript
    // server/api/kavach/[...].ts
    import { createKavach } from 'kavachos';
    import { kavachNuxt } from '@kavachos/nuxt';

    const kavach = createKavach({
      database: { provider: 'sqlite', url: 'kavach.db' },
    });

    export default kavachNuxt(kavach);
    ```

    With MCP OAuth:

    ```typescript
    import { createMcpModule } from 'kavachos/mcp';

    const mcp = createMcpModule({ config: { /* ... */ }, /* storage callbacks */ });
    export default kavachNuxt(kavach, { mcp });
    ```

    The default `basePath` is `/api/kavach`. To change it:

    ```typescript
    export default kavachNuxt(kavach, { basePath: '/api/auth' });
    ```
  </Tab>

  <Tab value="SvelteKit">
    `kavachSvelteKit` returns SvelteKit `RequestHandler` exports. Mount in a catch-all `+server.ts` file.

    ```typescript

    export const GET = handlers.GET;
    export const POST = handlers.POST;
    export const PATCH = handlers.PATCH;
    export const DELETE = handlers.DELETE;
    export const OPTIONS = handlers.OPTIONS;
    ```

    With MCP OAuth:

    ```typescript
    import { createMcpModule } from 'kavachos/mcp';

    const mcp = createMcpModule({ config: { /* ... */ }, /* storage callbacks */ });
    const handlers = kavachSvelteKit(kavach, { mcp });

    export const GET = handlers.GET;
    export const POST = handlers.POST;
    export const PATCH = handlers.PATCH;
    export const DELETE = handlers.DELETE;
    export const OPTIONS = handlers.OPTIONS;
    ```

    SvelteKit passes standard Web API `Request` objects natively, so no conversion is needed.
  </Tab>

  <Tab value="Astro">
    `kavachAstro` returns Astro `APIRoute` exports. Mount in a catch-all page.

    ```typescript
    // src/pages/api/kavach/[...path].ts

    const kavach = createKavach({
    ```

    ```typescript

    ```

    With MCP OAuth:

    ```typescript
    import { createMcpModule } from 'kavachos/mcp';

    const mcp = createMcpModule({ config: { /* ... */ }, /* storage callbacks */ });
    const handlers = kavachAstro(kavach, { mcp });
    ```

    Astro passes standard Web API `Request` objects natively, so no conversion is needed.
  </Tab>

## MCP endpoints with adapter

When you pass an `McpAuthModule` to any adapter, the following endpoints are mounted in addition to the standard KavachOS routes:

| Endpoint | Method | Purpose |
|---|---|---|
| `/.well-known/oauth-authorization-server` | GET | Authorization server metadata (RFC 8414) |
| `/.well-known/oauth-protected-resource` | GET | Protected resource metadata (RFC 9728) |
| `/mcp/register` | POST | Dynamic client registration (RFC 7591) |
| `/mcp/authorize` | GET | OAuth 2.1 authorization endpoint |
| `/mcp/token` | POST | Token exchange (code grant and refresh) |

All MCP endpoints include CORS headers (`Access-Control-Allow-Origin: *`) and handle OPTIONS preflight requests automatically.

If you do not pass `mcp` to the adapter, these endpoints return 404.

## Using without an adapter

If your framework is not listed, or you want full control, use the `createMcpModule` directly. The MCP module accepts standard `Request` objects and returns `Result` types that you convert to responses yourself.

```typescript
import { createKavach } from 'kavachos';
import { createMcpModule } from 'kavachos/mcp';

const kavach = createKavach({ /* ... */ });
const mcp = createMcpModule({ config: { /* ... */ }, /* storage callbacks */ });

async function handler(request: Request): Promise<Response> {
  const url = new URL(request.url);

  // Metadata discovery
  if (url.pathname === '/.well-known/oauth-authorization-server') {
    return Response.json(mcp.getMetadata());
  }

  if (url.pathname === '/.well-known/oauth-protected-resource') {
    return Response.json(mcp.getProtectedResourceMetadata());
  }

  // Client registration
  if (url.pathname === '/mcp/register' && request.method === 'POST') {
    const body = await request.json();
    const result = await mcp.registerClient(body);
    if (!result.success) {
      return Response.json(
        { error: 'invalid_client_metadata', error_description: result.error.message },
        { status: 400 },
      );
    }
    return Response.json(result.data, { status: 201 });
  }

  // Authorization
  if (url.pathname === '/mcp/authorize' && request.method === 'GET') {
    const result = await mcp.authorize(request);
    if (!result.success) {
      return Response.json(
        { error: result.error.code, error_description: result.error.message },
        { status: 400 },
      );
    }
    return Response.redirect(result.data.redirectUri, 302);
  }

  // Token exchange
  if (url.pathname === '/mcp/token' && request.method === 'POST') {
    const result = await mcp.token(request);
    if (!result.success) {
      return Response.json(
        { error: result.error.code, error_description: result.error.message },
        { status: result.error.code === 'INVALID_CLIENT' ? 401 : 400 },
      );
    }
    return Response.json(result.data);
  }

  // Protect your own endpoints
  const authResult = await mcp.middleware(request);
  if (!authResult.success) {
    return new Response('Unauthorized', { status: 401 });
  }

  const session = authResult.data;
  return Response.json({ userId: session.userId, scopes: session.scopes });
}
```

## REST API endpoint reference

All adapters mount the same set of REST routes. These are the KavachOS core endpoints (not MCP):

| Endpoint | Method | Description |
|---|---|---|
| `/agents` | GET | List agents (filterable by userId, status, type) |
| `/agents` | POST | Create an agent |
| `/agents/:id` | GET | Get agent by ID |
| `/agents/:id` | PATCH | Update agent (name, permissions, expiry, metadata) |
| `/agents/:id` | DELETE | Revoke an agent |
| `/agents/:id/rotate` | POST | Rotate agent token |
| `/authorize` | POST | Authorize an action by agent ID |
| `/authorize/token` | POST | Authorize an action by bearer token |
| `/delegations` | POST | Create a delegation chain |
| `/delegations/:id` | DELETE | Revoke a delegation |
| `/delegations/:agentId` | GET | List delegation chains for an agent |
| `/audit` | GET | Query audit logs (filterable) |
| `/audit/export` | GET | Export audit logs as JSON or CSV |
| `/dashboard/stats` | GET | Dashboard overview statistics |
| `/dashboard/agents` | GET | Dashboard agent listing |
| `/dashboard/audit` | GET | Dashboard audit log view |
