title: Reverse proxy gateway for AI agent auth
description: Run a reverse proxy in front of any HTTP API or MCP server to check agent tokens, permissions, rate limits and audit logs.
icon: shield-halved
---

```bash
npx @glinr/theauth-gateway --config gateway.json --database ./theauth.db --port 3000
```

Needs Node 20 or newer. For MCP servers, use [Gateway for MCP servers](/gateway-mcp).

<Steps>
<Step>

### Create an agent

Create it in the gateway's SQLite file. Keep `agent.token`.

```typescript
import { createTheAuth } from '@glinr/theauth';

const theauth = await createTheAuth({
  database: { provider: 'sqlite-native', url: './theauth.db' },
  agents: { enabled: true },
});

const agent = await theauth.agent.create({
  ownerId: 'user-1', // must be an existing user id
  name: 'support-bot',
  type: 'autonomous',
  permissions: [{ resource: 'api', actions: ['read'] }],
});
console.log(agent.token);
```

</Step>
<Step>

### Write gateway.json

```json
{
  "upstream": "http://localhost:8080",
  "policies": [
    { "path": "/health", "public": true },
    {
      "path": "/api/**",
      "method": "GET",
      "requiredPermissions": [{ "resource": "api", "actions": ["read"] }]
    },
    {
      "path": "/api/**",
      "requiredPermissions": [{ "resource": "api", "actions": ["write"] }]
    }
  ],
  "rateLimit": { "windowMs": 60000, "max": 100 }
}
```

</Step>
<Step>

### Start and call

Run the command at the top, then:

```bash
curl http://localhost:3000/api/items                                         # 401
curl -H "Authorization: Bearer $AGENT_TOKEN" http://localhost:3000/api/items # proxied
```

</Step>
</Steps>

<Warning>
The default `--database` is `:memory:`, so protected requests get 401. The CLI is SQLite only.
</Warning>

## Request order

The first matching policy wins.

| Step | Check | On failure |
|------|-------|------------|
| 1 | `/_theauth/health`, then CORS preflight | None |
| 2 | First policy matching path glob and method | Still needs a token, but no permission check or route limit |
| 3 | Agent token, unless `public` or `requireAuth: false` | 401, `WWW-Authenticate: Bearer` |
| 4 | Global and policy rate limits | 429, `Retry-After` |
| 5 | Every `requiredPermissions` pair | 403 |
| 6 | Forward, then audit | None |

Error codes: `UNAUTHORIZED`, `FORBIDDEN`, `RATE_LIMITED`, `PAYLOAD_TOO_LARGE`, `BAD_GATEWAY`, `GATEWAY_TIMEOUT`.

## Always on

| Behavior | Detail |
|----------|--------|
| Fixed upstream | Clients cannot pick a host. Only `http` and `https`, no embedded credentials. |
| Tokens stripped (breaking) | `Authorization` and `DPoP` are removed. Keep them with `--forward-auth` or `stripAuthHeader: false`. |
| Headers | Client `Forwarded`, `X-Forwarded-*` and `X-Real-IP` are dropped. `X-Forwarded-For` comes only from `trustedProxy`. |
| Redirects | Not followed. Upstream `Location` is rewritten to the gateway. |
| Body and timeout | Over `maxBodyBytes` gets 413. No headers within `upstreamTimeoutMs` gets 504. |
| Streaming | SSE and streamable HTTP pass through. A disconnect cancels the upstream. |
| 502 | Says only that the upstream is unreachable. |

## CLI flags

| Flag | Default | Purpose |
|------|---------|---------|
| `--upstream`, `-u` | required | Upstream URL |
| `--port`, `-p` | `3000` | Listen port |
| `--database`, `-d` | `:memory:` | SQLite path |
| `--config`, `-c` | none | `gateway.json` path |
| `--forward-auth` | off | Send `Authorization` upstream |
| `--no-audit` | off | Audit off |
| `--max-body-bytes` | `10485760` | Body cap, 10 MiB |
| `--trusted-proxy-count` | `0` | Proxies in front |
| `--trusted-header` | none | Edge header, such as `cf-connecting-ip` |
| `--mcp-resource`, `--mcp-issuer`, `--mcp-scope` | none | [MCP mode](/gateway-mcp) |

`--strip-auth` is still accepted and does nothing.

## gateway.json

```jsonc
{
  "upstream": "http://localhost:8080",         // required, http or https only
  "audit": true,
  "stripAuthHeader": true,                     // false keeps Authorization upstream
  "maxBodyBytes": 5242880,                     // default 10485760 (10 MiB)
  "upstreamTimeoutMs": 15000,                  // default 30000 (30 s for headers)
  "cors": { "origins": ["https://app.example.com"], "credentials": true }, // unlisted callers never get the first origin
  "rateLimit": { "windowMs": 60000, "max": 100 }, // per agent, or per client on anonymous routes
  "trustedProxy": { "trustedProxyCount": 1 },
  // "mcp" turns on MCP mode. "basePath" is accepted but has no effect on routing.
  "policies": [
    { "path": "/health", "public": true },     // micromatch: /api/* one level, /api/** any depth
    {
      "path": "/api/**",
      // requiredPermissions checks the agent's own permissions only, not delegated ones
      "requiredPermissions": [{ "resource": "api", "actions": ["read", "write"] }],
      "rateLimit": { "windowMs": 60000, "max": 20 }
    }
  ]
}
```

Policy fields: `path`, `method`, `public`, `requireAuth`, `requiredPermissions`, `requiredScopes` (MCP only), `rateLimit`. Validated on start.

## Embedded mode

Pass a `createTheAuth()` instance as `theauth`. For Postgres or MySQL, use this mode.

```typescript
import { createTheAuth } from '@glinr/theauth';
import { createGateway } from '@glinr/theauth-gateway';

const theauth = await createTheAuth({
  database: { provider: 'sqlite-native', url: 'theauth.db' },
  agents: { enabled: true },
});

const gateway = createGateway({
  upstream: 'http://localhost:8080',
  theauth,
  policies: [
    { path: '/health', public: true },
    { path: '/api/**', requiredPermissions: [{ resource: 'api', actions: ['read'] }] },
  ],
});

await gateway.listen(3000);

// Or mount it in your own server: Web Request in, Response out.
const response = await gateway.handleRequest(request);
```

## Docker and Kubernetes

Run the gateway as a sidecar. Expose only its port.

```dockerfile
CMD ["npx", "@glinr/theauth-gateway", "--config", "/etc/gateway.json", "--database", "/data/theauth.db", "--port", "3000"]
```

## Limits

- **Direct upstream access bypasses it.** Bind the upstream to a private network.
- **No body inspection.** Policies match method and path only.
- **Paths match as the gateway sees them.** Test encoded paths such as `%2F`.
- **HTTP only.** No TLS or WebSocket. Put a TLS proxy in front.
- **Rate limits are in memory, per process.**
- **Audit is not an access log.** It records a permission check, not the decision.
- **Agent revocation is immediate.** MCP OAuth limits: [MCP page](/gateway-mcp#limits).
